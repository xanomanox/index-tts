## 1.1 Speech Synthesis with Emotion Reference Audio


### 1.1.1 Style Transfer 

Style seems to transfer reasonably well from candidate reference audio generated by Qwen3-TTS Custom Voice with instruction.

### 1.1.2 Emotion Control Weight

Supply a wave file with desired prosody and emoting, then click synthensize.

Only enabled by checking the "Show experimental features" checkbox.

**Results**
- 1 = max. Heavy style transfer is evident in synthesized output.
- .49 = halfway. Some style transfer is evident.
- 0 = none. No style transfer is evident.

Thoughts: Weight control has clear affect on output. The variance is really subjective for some vs full weight, so this knob is more of an on-off switch for basic scenarios.
